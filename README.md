# 植物大战僵尸 (Plants vs Zombies)

一个基于HTML5 Canvas和JavaScript的植物大战僵尸游戏实现。

## 游戏特色

### 🌱 植物系统
- **向日葵** (50阳光) - 每8秒产生25阳光
- **豌豆射手** (100阳光) - 发射豌豆攻击僵尸
- **坚果墙** (50阳光) - 高防御力的防御植物
- **双发射手** (200阳光) - 连续发射两发豌豆
- **寒冰射手** (175阳光) - 发射冰豌豆，减慢僵尸速度

### 🧟 僵尸系统
- **普通僵尸** - 基础敌人，移动速度中等
- **路障僵尸** - 头戴路障，防御力更强
- **铁桶僵尸** - 头戴铁桶，拥有最高防御力

### ✨ 游戏特效
- 粒子效果系统（爆炸、收集、死亡效果）
- 屏幕震动效果
- 动态背景（移动云朵、草地纹理）
- 音效系统（射击、收集、爆炸等音效）

### 📊 游戏机制
- 波次系统：每30秒一波僵尸
- 阳光资源管理
- 健康条显示
- 游戏统计（击杀数、种植数等）
- 碰撞检测系统

## 操作说明

### 鼠标操作
- **点击植物卡片** - 选择要种植的植物
- **点击网格** - 在对应位置种植植物
- **点击阳光** - 收集阳光资源

### 键盘操作
- **M** - 开启/关闭音效
- **R** - 游戏结束后重新开始
- **ESC** - 取消当前植物选择

## 游戏目标

- 🛡️ 保护你的房子不被僵尸入侵
- 🌻 合理种植向日葵收集阳光
- ⚔️ 使用各种植物击败不同类型的僵尸
- 🏆 坚持尽可能多的波次

## 技术特点

### 代码结构
- **面向对象设计** - 使用ES6类语法
- **工厂模式** - 植物和僵尸的创建
- **模块化管理** - 音效、背景、特效等独立管理器
- **游戏循环** - 60FPS流畅游戏体验

### 核心系统
1. **游戏引擎** - 主循环、状态管理
2. **渲染系统** - Canvas绘制、动画效果
3. **物理系统** - 碰撞检测、移动逻辑
4. **音频系统** - Web Audio API音效
5. **粒子系统** - 视觉特效

### 性能优化
- 对象池管理
- 高效的碰撞检测
- 自动垃圾回收
- 平滑的动画插值

2. 用现代浏览器打开 `index.html`
3. 点击植物卡片开始游戏

## 开发说明

本游戏完全使用原生JavaScript开发，没有使用任何第三方框架。代码总量超过3000行，包含完整的游戏系统：

- 游戏主类：Game
- 植物类：Plant, Sunflower, Peashooter, Wallnut, Repeater, SnowPea
- 僵尸类：Zombie, BasicZombie, ConeZombie, BucketZombie
- 子弹类：Projectile, Pea, IcePea
- 资源类：Sun
- 粒子类：Particle, CollectEffect, HitEffect, DeathEffect
- 管理器类：AudioManager, BackgroundManager, EffectManager, GameStats

游戏展示了现代JavaScript的强大功能和面向对象编程的最佳实践。
